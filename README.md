# How Many Tabs Do You Have Open?

> 47

One honest number, counted from a real browser session: forty-seven tabs open at once — a working browser that never quite gets closed. It is the accumulated trail of a research-heavy day: half-finished articles, documentation pages, tabs kept "just in case", and the dozen things that were supposed to be read five minutes ago. High enough to make anyone who keeps a tidy browser wince, low enough to be a real count from a real person who does too much in a browser.

## Run

```sh
node main.ts
```

This writes the entry number to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt` when the variable is unset).
